# DistriSight — Product Website

**A Secure Data Intelligence, Quality Management and Decision Support Platform for Wholesale Distributors.**  
*Trusted Data. Clear Insights. Smarter Distribution.*

## Overview

This repository contains the complete, production-ready product website for the **DistriSight** Final Year Project (FYP). Designed with an editorial B2B SaaS aesthetic, it communicates technical depth, data reliability, bilingual conversational analytics (English and Roman Urdu), lead-time-aware demand forecasting, and defense-in-depth cybersecurity.

## Design System & Color Palette

- **Primary Dark:** Midnight Navy (`#101D2B`)
- **Main Background:** Warm Ivory (`#F5F4EF`)
- **Secondary Background:** White (`#FFFFFF`)
- **Primary Accent:** Deep Teal (`#176B62`)
- **Secondary Accent:** Muted Amber (`#D9A441`)
- **Main Text:** Charcoal (`#202A32`)
- **Secondary Text:** Slate Grey (`#697681`)
- **Borders:** Soft Grey (`#E4E7E5`)
- **Typography:** Plus Jakarta Sans (Headings), Inter (Body), JetBrains Mono (Technical telemetry & SQL)

## Development & Deployment

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle (Vercel / Netlify ready)
npm run build
```
